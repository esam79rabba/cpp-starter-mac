# Changelog

## 0.0.1

First release.

- F5, Ctrl+F5 and Ctrl+Shift+B build and run the program in the terminal, with debugging through Apple's `lldb-dap`.
- Get started page, one-click install of Apple's command line tools, and **C++: Check Tools**.
- Compiler errors shown in the Problems panel with plain-English explanations.
- Visual Studio `.sln` and `.vcxproj` support.
- Compatibility header for `system("pause")`, `scanf_s` and friends, and for `pch.h`, `stdafx.h` and `conio.h`.
- clangd configured automatically so beginners see no false errors.
